# ms-thesis-geonet-tes-mpc
This repository contains code which simulates sub-optimal and optimal supervisory predictive controllers designed for the DC Nanogrid + ReNEWW House networked geothermal with TES system. This is one of the main contributions of Liam Q. Johnson's master's thesis, "Predictive Control of a Residential Geothermal Network with Thermal Energy Storage."
